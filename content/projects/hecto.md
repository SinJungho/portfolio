# 헥토파이낸셜 폐기물 수거 서비스

`2024.11–2025.05` · 프론트엔드 개발자

주소 선택부터 수거 신청과 결제까지 이어지는 웹 서비스의 프론트엔드 기능을 맡았습니다.

## 맡은 범위

- 도로명주소 API·Naver Maps와 API Route·`postMessage` 기반 주소 검색 팝업을 연결하고 주소·좌표·관할 지자체를 검증했습니다.
- 이미지 형식·용량을 검증하고 crop·Base64 변환을 거쳐 AI 인식 결과를 화면과 신청 항목에 반영했습니다.
- PG 결제창과 결제 수단별 완료 흐름을 연결하고, 결제창 종료와 결제 성공을 구분하기 위해 서버 결제 상태를 polling했습니다.
- SWR로 서버 상태를, Zustand로 화면 상태를 관리하고 백엔드와 API 필드·응답 타입·오류 계약을 조율했습니다.
- 모바일 UI·모달·라우팅·이미지 재선택·결제 취소와 같은 경계 이슈를 수정했습니다.

## 사용 기술

Next.js, React, TypeScript, Tailwind CSS, SWR, Zustand, React Hook Form, Zod, Naver Maps API

## 배운 점

이 프로젝트에서 어려운 부분은 개별 화면보다 지역 선택, 인증, 주소, 이미지 인식, 신청, 결제 상태가 다음 단계로 정확히 넘어가는지 확인하는 일이었습니다. 외부 시스템은 성공 응답만 연결하는 것보다 새 창 종료, SDK 로드 지연, 잘못된 파일, 결제 상태 불일치 같은 실패 조건을 먼저 정리해야 안정적으로 동작했습니다.
